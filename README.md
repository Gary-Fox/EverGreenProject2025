# How to Run the Project
First, open a terminal or command prompt and `cd` into the project's root directory. Then, run one of the commands below depending on your platform:

If on Windows, run this command:

```
gradlew.bat bootRun
```

If on macOS, Linux, or any other platform, run this command:

```
./gradlew bootRun
```

The program should then run successfully.
